# core

High-throughput / core domain service for the Divine Hands HMS, written in Go.

- Module: `github.com/xmendevs/divine-hands-hospital-app/services/core`
- Entrypoint: `cmd/server/main.go`
- Run: `go run ./cmd/server` (listens on `:8080`, override with `PORT`)

Business logic, migrations, and API surface are implemented in later build phases.
