# analytics

Python-oriented service for the Divine Hands HMS (reporting, analytics,
document processing, ML-enabled features), built with FastAPI.

- Managed with [uv](https://docs.astral.sh/uv/)
- Install: `uv sync`
- Run: `uv run uvicorn app.main:app --reload` (or `uv run fastapi dev app/main.py`)

Endpoints and business logic are implemented in later build phases.
