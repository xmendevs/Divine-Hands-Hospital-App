# Stage 1: Design Tokens & Global Foundation

## Goal
Establish a single source of truth for the visual design system in `@hims/ui` matching the dark-navy sidebar, card layout, and shift badge palette, wire a global CSS reset, and tokenize the login screen.

## Context & Rules
- **Stack:** React 19 + TypeScript, Electron, Vite. Inline `CSSProperties` only.
- **Shared Package:** `packages/ui` (consumed as `@hims/ui`).
- **Target App:** `apps/desktop`.
- **Constraint:** Zero external CSS/icon runtime dependencies. Keep all API logic untouched.
- **Verification Gate:** `pnpm typecheck && pnpm lint && pnpm test && pnpm build` must pass.

## Prompt to AI Agent
