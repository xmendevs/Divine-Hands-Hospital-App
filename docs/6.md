# Stage 6: Feedback, Alerts & Micro-Interactions

## Goal
Implement system-wide interaction feedback: toast notifications for mutations, confirmation dialogs for destructive actions, and smooth UI transitions.

## Context & Rules
- Do not alter API mutation triggers or request bodies.
- Maintain existing success and error notification text verbatim.

## Prompt to AI Agent
Implement system-wide feedback mechanisms and micro-interactions across `apps/desktop/src` using `@hims/ui`.

1. **Global Toast System:**
   - Create `ToastProvider` and `useToast()` hook in `@hims/ui` (or `apps/desktop/src/ui/`).
   - Mount `ToastProvider` at the root of `App.tsx`.
   - Replace ad-hoc inline success/failure messages across all pages with `toast.success(message)` and `toast.error(message)`, preserving exact wording.
2. **Destructive Action Confirmations:**
   - Implement `useConfirm()` / `ConfirmDialog` primitive for irreversible operations (e.g., delete patient, void invoice, cancel shift, revoke credential) where direct deletion previously fired without confirmation.
3. **Interactive States:**
   - Add 150ms ease transitions for sidebar nav items, tab navigation underlines, buttons, and table row hover states (`backgroundColor: rgba(0,0,0,0.02)`).
   - Ensure buttons enter disabled loading state with a spinner when mutations are executing.

## Verification Steps
- Run `pnpm typecheck && pnpm lint && pnpm test && pnpm build`.
- Trigger mutations and verify toast popups, delete confirmation dialogs, and loading states.
