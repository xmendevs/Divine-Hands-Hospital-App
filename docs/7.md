# Stage 7: Final Polish, Accessibility & Release Builds

## Goal
Conduct a full codebase consistency audit, verify accessibility, test print stylesheets, and produce production installer executables.

## Context & Rules
- Both client and server Electron distribution targets must build without warnings or errors.
- Confirm zero lingering inline hex styles outside `theme.ts`.

## Prompt to AI Agent
Perform a final visual consistency, accessibility, and build audit on the Divine Hands Hospital desktop client.

1. **Token & Component Audit:**
   - Confirm no raw hex values, un-tokenized font sizes, or ad-hoc margins exist in `apps/desktop/src`.
   - Verify all 9 pages strictly conform to the unified layout: `Sidebar` → `PageHeader` → `TabNav` → `Card` → `DataTable`/`MatrixGrid`.
2. **Layout & Print Verification:**
   - Test responsiveness down to `1024×768` window dimensions; ensure matrix tables scroll without breaking the main shell.
   - Check Billing invoice and receipt views to verify print stylesheets render cleanly without sidebar or background artifacts.
3. **Dead Code Elimination:**
   - Remove all unused legacy style objects, obsolete test fixtures, and unneeded helper functions.
4. **Release Builds:**
   - Run the complete verification suite from repo root:
     ```bash
     pnpm format:check
     pnpm lint
     pnpm typecheck
     pnpm test
     pnpm build
     ```
   - Generate Electron distribution binaries from `apps/desktop`:
     ```bash
     pnpm dist
     pnpm dist:server
     ```
   - Confirm both desktop client and server installer executables build with zero errors.

## Acceptance Criteria
- All lint, typecheck, test, and build scripts pass cleanly.
- Electron client and server installer binaries are generated successfully.
