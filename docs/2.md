# Stage 2: Shared UI Component Kit (`@hims/ui`)

## Goal
Build a dependency-free React component library in `packages/ui` supporting page headers, secondary tab bars, structured cards, matrix grids, and status badges.

## Context & Rules
- All components reside in `packages/ui/src/` and export through `packages/ui/src/index.ts`.
- Inline `CSSProperties` referencing `theme.ts` exclusively.
- Icons must be hand-crafted inline SVGs (no external icon libraries).
- Pass all unit tests and repo-wide build checks.

## Prompt to AI Agent
Expand `packages/ui` into the shared component kit for the Divine Hands Hospital desktop app. Every component must use inline `CSSProperties` referencing `theme.ts`, have full TypeScript types, and export from `packages/ui/src/index.ts`.

1. **Core Primitives (`packages/ui/src/`):**
   - **`Button`:** Support variants (`primary` blue `#2563eb`, `secondary` dark slate `#334155`, `outline`, `ghost`, `danger`), size (`sm`, `md`), loading state with integrated spinner, and icon slots.
   - **`PageHeader`:** Standardized top container:
     - Left: Title (bold `1.25rem`) and Description/Subtitle (muted text).
     - Right: Status badge slot + Action button cluster.
   - **`TabNav`:** Underline sub-navigation tab bar:
     - Horizontal items with active border-bottom (`2px solid #2563eb`), active blue text, and inactive muted slate text.
   - **`Card`:** Container with white surface, `#e2e8f0` border, `radius.lg`, padding, and optional header toolbar slots (title + hint banner on left, dropdown selector on right).
   - **`ShiftBadge` & `StatusBadge`:** Compact pill badges (`radius.full`, small bold text):
     - `StatusBadge`: `draft`, `submitted`, `approved`, `active`, `inactive`.
     - `ShiftBadge`: `day` (☀️ Day), `night` (🌙 Night), `aft` (🌅 Aft), `off` (🌴 Off).
   - **`DataTable` / `MatrixGrid`:** Table container supporting dense cell layouts, fixed header rows, alternating/clean borders, and horizontal scrolling.
   - **`Input`, `Select`, `Textarea`, `Checkbox`:** Consistent input controls with focus border rings, disabled states, and error styling.
   - **`FormField`:** Label, helper text, error message, and required indicator wrapper.
   - **`Modal`:** Overlay, focus-trap, escape-key handler, header with close button, body, and footer actions.
   - **`Spinner`, `EmptyState`, `Toast`**.
2. **Inline SVG `Icon` Component:**
   - Custom SVG component using `viewBox="0 0 24 24"`, `fill="none"`, `stroke="currentColor"`, `strokeWidth="2"`.
   - Support icons: `users`, `clipboard`, `flask`, `pill`, `box`, `cash`, `calendar`, `book`, `chat`, `gear`, `logout`, `edit`, `refresh`, `plus`, `search`, `close`, `check`, `warning`, `trash`, `lock`, `sun`, `moon`, `chevron-left`, `chevron-right`, `file-text`, `filter`.
3. **Tests:**
   - Retain `Button.test.tsx` and add smoke tests for `PageHeader`, `TabNav`, `ShiftBadge`, `Modal`, and `Icon`.
4. **Documentation:** Update `packages/ui/README.md` with usage examples.

## Verification Steps
- Run `pnpm test` to execute all `@hims/ui` unit tests.
- Run `pnpm typecheck && pnpm lint && pnpm build` from the repo root.
